## Робота програми та опис інтерфейсу

### 1. Початковий вигляд програми
На формі розміщено елементи керування: текстове поле для введення кількості інтервалів (`textBox1`), список для виведення текстової таблиці результатів (`listBox1`), елемент `chart1` для побудови графіка функції за варіантом №15 ($y = \sin(e^x) - \ln^2 x$), а також кнопки для розрахунку, побудови та очищення форми.


### 2. Результат табулювання та виведення в таблицю

* **Опис роботи:** У поле введення (`textBox1`) користувач вводить кількість кроків табулювання $k$ (значення має бути більшим за нуль). При натисканні першої кнопки програма перевіряє введені дані, обчислює крок $h = (b - a) / k$ на заданому відрізку $[1.5; 5.5]$ та за допомогою циклу розраховує значення функції за варіантом: $y = \sin(e^x) - (\ln x)^2$. Отримані пари значень виводяться у вигляді акуратної таблиці в компоненті `listBox1` з округленням до двох знаків після коми.

### 3. Побудова графіка функції

* **Опис роботи:** При натисканні кнопки побудови графіка програма аналогічно виконує обчислення значень у циклі, після чого за допомогою методу `AddXY(x, y)` передає координати точок у компонент `chart1`. На графіку відображається плавна зелена лінія заданої функції з маркерами, налаштованою сіткою та легендою.


### 4. Очищення даних

* **Опис роботи:** Третя кнопка (`button3`) відповідає за повне очищення робочої області: вона очищує текстове поле `textBox1`, видаляє рядки з таблиці (`listBox1`) та стирає побудовані точки на графіку `chart1`, підготовлюючи програму до нових обчислень.
